# SQUi Official Website v2 — Simple

客服信箱已設定為：`squicompany@gmail.com`

## 上傳到現有 GitHub Repository

1. 解壓縮 ZIP。
2. 進入 `squiapp/squi-website`。
3. 點 **Add file → Upload files**。
4. 將本資料夾內的所有檔案與 `assets` 資料夾拖入上傳區。
5. 選擇覆蓋同名檔案並 Commit changes。
6. 等待約 1–3 分鐘後重新整理網站。
